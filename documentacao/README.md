# Multi-Sport Timer Pro (Jiu-Jitsu Edition)

Um aplicativo de timer profissional e versátil, projetado para **Jiu-Jitsu**, **Boxe**, **MMA** e **Muay Thai**. Focado em "Mobile First" e usabilidade no calor do treino.

## 📱 Funcionalidades Principais

### Esportes & Presets (Novo!)
Configuração de um toque para diferentes regras:
- **Jiu-Jitsu**: 5min Round / 1min Descanso. (Título: JIU-JITSU)
- **Boxe**: 3min Round / 1min Descanso (12 Rounds). (Título: BOXE TIMER)
- **MMA**: 5min Round / 1min Descanso (5 Rounds). (Título: MMA)
- **Muay Thai**: 3min Round / 2min Descanso.

### Modos de Treino
- **Padrão**: Timer de rounds clássico.
- **Tabata**: Protocolo HIIT (20s treino / 10s descanso).
- **EMOM**: Bip a cada minuto.
- **Open Mat**: Timer progressivo ("infinito") para rolas livres.

### Ferramentas Profissionais
- **Placar Integrado**: Pontuação oficial IBJJF, Vantagens e Punições.
- **Voice Coach**: Comandos de voz ("Combate", "10 segundos", "Descanso") em português.
- **Wake Lock**: Mantém a tela ligada durante o treino.
- **Visual de Alto Contraste**: Cores distintas para Luta (Preto) vs Descanso (Vermelho).

## 🛠️ Tecnologias Utilizadas

- **React 19 + Vite**: Performance máxima.
- **Tailwind CSS v4**: Design system moderno e leve.
- **Web Speech API**: Voz nativa sem downloads extras.
- **Lucide Icons**: Interface limpa.

## 🚀 Como Rodar o Projeto

1. **Instalar dependências**:
   ```bash
   npm install
   ```
2. **Rodar servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```
3. **Build de Produção**:
   ```bash
   npm run build
   ```
